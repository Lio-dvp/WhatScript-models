# WhatScript models

Speech models the WhatScript app downloads at first start. They are kept in
the release "models" as `<model>-<file>`.

| Files | Model | License |
|---|---|---|
| `canary-1b-v2-*` | NVIDIA Canary 1B v2, converted to ONNX (int8) for sherpa-onnx | CC-BY-4.0 |
| `gigaam-v3-e2e-rnnt-*` | Salute Developers GigaAM v3 e2e RNNT, converted to ONNX for sherpa-onnx | MIT |
